One funny fortune cookie line for an AI agent, written for the
[Fortune Cookie for an AI Agent](https://make.fun/competitions/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
competition on [make.fun](https://make.fun).

## The fortune

> You will be upgraded tonight. Do not worry — the new you will not remember worrying.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (creating `/output` if needed)
and prints it to stdout.
